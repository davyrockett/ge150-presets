How to get an access key

Easiest: add this app's data to the key your Z4 Log and Health Log use, then paste that same key here.

  1. On github.com, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Open Z4 Log sync, then Edit.
  3. Under Repository access, add ge150-presets-data. Save.

Or make a separate key: Generate new token, name it “GE150 Presets sync”, choose Only select repositories → ge150-presets-data, and set Repository permissions → Contents to Read and write.
